This guide outlines a simple and effective method to reset the root password on a Linux VPS without reinstalling the operating system or risking data loss. It explains how to regain access by booting the machine using a specially prepared password reset image. As EDIS supplies unmodified OS images without pre-installed KVM guest drivers, password changes via the admin panel are not supported. Nevertheless, by following the steps in this guide, you can securely set a new root password on your KVM-based Linux VPS. This method is suitable for a wide range of distributions, including Ubuntu, Debian, CentOS, Rocky Linux, AlmaLinux, and even Arch Linux.
### Access the VPS Management Portal

*   Log in to your [VPS Management Portal](https://manage.edisglobal.com/clientarea.php)

*   Locate your VPS under **Services → My Services**

### Mount password reset helper image and boot

* [**Enable VNC Server**](/vps-management/enable-vnc-server)

* Click [Mount ISO](/vps-management/mount-iso-image)

* In the drop-down list select image: **1_Password-Reset-Helper.iso** 💿

* Check the box ✅ **force reset & boot from the selected ISO** then click the **Mount ISO** button

  ![Select the Password Reset Helper ISO](/images/portal-mount-iso-dialog.png)

  _The screenshot shows the image selection before enabling force reset._

*   Open the noVNC or connect by VNC client (RealVNC Viewer, TightVNC Viewer, UltraVNC)

### Open the browser console

1. Click "**Open Console**" to see console output

2. Click into the noVNC browser window to set focus

3. Wait patiently while the ISO loads automatically:

   ![SystemRescue boot menu with the default boot option highlighted](/images/password-reset-boot-menu.png)

4. Once the ISO has successfully loaded, the helper prompts you to change the password:

   ![Linux recovery helper prompting for a new root password](/images/password-reset-enter-password.png)

5. Enter a new strong password and press Enter ⌨️

6. The helper displays the new password and **Continue ?**. Check the password, then press **Enter** to proceed. The password is masked in the screenshot below; the actual helper displays it.

   ![Continue prompt after password entry; the password is hidden](/images/password-reset-confirm-password.png)

7. When **Linux root password has been reset.** appears, press **Enter** at the unmount-and-exit prompt:

   ![Password reset confirmation and prompt to unmount and exit](/images/password-reset-reset-complete.png)

8. Next, the reboot process will begin automatically. When the OS has rebooted, log in as **root** with the new password. Run `whoami` to confirm that the session is using the root account:

   ![whoami returns root after logging in with the new password](/images/password-reset-root-login.png)


### Unmount the ISO

Once the password is reset, make sure to [unmount the ISO](/vps-management/mount-iso-image) (**Password Reset Helper**) image. You can do this in the VPS Management Portal.

### Disable VNC access

Now close the **noVNC** tab and [disable VNC access](/vps-management/enable-vnc-server) in the VPS Management Portal.

### Credentials updated successfully! 🐧

You have successfully reset the Linux root password using the provided recovery image. The system now uses the updated credentials, and your administrative access is restored. You can proceed with any necessary maintenance or configuration tasks as needed, knowing that control of the environment has been re-established.
