This guide describes a common method to regain access to a Windows Server OS when you forget or lose the password for an administrator account. You don't need to reinstall the operating system, and no data is lost.

### Access the VPS Management Portal

*   Log in to your [VPS Management Portal](https://manage.edisglobal.com/clientarea.php)

*   Locate your VPS under **Services → My Services**

### Mount password reset helper image and boot

* [**Enable VNC Server**](/vps-management/enable-vnc-server)

* Click [Mount ISO](/vps-management/mount-iso-image)

* In the drop-down list select image: **1_Password-Reset-Helper.iso**

* Check the box **force reset & boot from the selected ISO** then click the **Mount ISO** button

  ![Select the Password Reset Helper ISO](/images/portal-mount-iso-dialog.png)

  _The screenshot shows the image selection before enabling force reset._

*   Open the noVNC or connect by VNC client

### Open the browser console

1. Click "**Open Console**" to see console output

2. Click into the noVNC browser window to set focus

3. The ISO will load automatically. When it is loaded, you can see this notification:

   ![Reset Windows Password](/assets/UVFJBNhdbn1c73-chntpw.png)

4. Press Enter

5. Select -> 1 and press Enter:

   ![Reset Windows Password](/assets/ix5iD2dZZyen4P22emv-resetadminpassword.png)

6. Select -> q and press Enter:

   ![Reset Windows Password](/assets/4iwS9tjeowHQfbaaQSC-quiteditinguser.png)

7. Select -> y and press Enter:

   ![Reset Windows Password](/assets/Mu5oWRhP2anwRDejnqh-writechanges.png)

8. Accept the changes made by pressing Enter:
   ![Reset Windows Password](/assets/mHzEbq4n4DXgiT5iVFz-umount.png)

### Unmount the ISO

Once the password is reset, make sure to [unmount the ISO](/vps-management/mount-iso-image) (**Password Reset Helper**) image. You can do this in the VPS Management Portal.

### Reboot and test

After rebooting, Windows will automatically log in to the Administrator account **without requesting a password**. You **must set a new password** by opening the CMD (Command Prompt) with administrative rights:
![Reset Windows Password](/assets/nB_DvyqQcZNKEL5141Wak_win1.jpeg)

In the terminal window that opens, run the command:
```shell
net user Administrator newpassword
```
   Where:
   \- `Administrator` is the Administrator account in Windows that has full system control
   \- `newpassword` is a new password.

   ![Reset Windows Password](/assets/q7wiAyHP8mf8iXnKbh1HU_newpassword.png)

### Disable VNC access

Now close the **noVNC** tab and [disable VNC access](/vps-management/enable-vnc-server) in the VPS Management Portal.

### 🎉 Congratulations!

You've successfully updated your Windows Administrator password. Now, try logging into the server with your new credentials. This is crucial to ensure that the password change took effect and that you have regained access to your server. Happy computing! :)
