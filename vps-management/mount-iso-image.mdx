## Mount an ISO image on your VPS

1. Open the [VPS Management Portal](https://manage.edisglobal.com/clientarea.php), then **Services → My Services**.
2. Select your VPS and open **Server Information → Mount ISO**.
3. Select an image from the dropdown. You can use a provided image or an ISO you [uploaded yourself](/vps-management/bring-your-own-iso).
4. Decide whether to attach the image only or also restart into it, then click **Mount ISO**.

### Attach only or boot immediately?

- Leave **force reset & boot from the selected ISO** unchecked to attach the image without requesting an immediate reset.
- Select it when you are ready to reset the VPS and boot the ISO. This interrupts the running operating system and its connections; save your work first.

Open [VNC / Open Console](/vps-management/enable-vnc-server) to follow boot output and use the installer or rescue environment. If you attach the image without resetting, restart when ready and use the boot menu to select the virtual CD-ROM.

Mounting an ISO alone does not reinstall the VPS. Follow the selected image's instructions, and unmount the image when finished so the VPS can boot from its normal disk.
