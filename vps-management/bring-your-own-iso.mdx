## Upload your own ISO

Use a custom ISO to install an operating system manually or boot a recovery environment.

1. Open the [VPS Management Portal](https://manage.edisglobal.com/clientarea.php).
2. Open **Services → My Services**, then select your VPS.
3. On **Server Information**, click **Upload ISO** in **Server management**. The dialog is titled **Download ISO**.

## Option 1: download from a URL

Select **HTTP Upload**, enter a direct HTTP or HTTPS URL to the ISO file, and click **Download ISO from another server**. Use a link to the file itself, not a download page. Wait until the download finishes.

## Option 2: upload from your computer

Select **Local Upload**, click **Choose file**, and select the `.iso` file on your computer. Then click **Upload ISO** and wait for the transfer to finish. The button remains disabled until a file is selected.


<Frame caption="Choose an ISO file to enable Upload ISO.">
  <img src="/images/portal-upload-local-dialog.png" alt="Local Upload tab showing the file chooser before a file has been selected" style={{ maxWidth: "520px", margin: "0 auto" }} />
</Frame>


## Mount and boot the uploaded image

After the transfer completes, close this dialog and open **Mount ISO**. Select the custom ISO filename shown for your VPS, then follow the [mount and boot instructions](/vps-management/mount-iso-image). Use [VNC / Open Console](/vps-management/enable-vnc-server) to work through the installer.

Uploading or attaching an ISO does not install an operating system by itself. An installer can erase the VPS disk when you select its installation or partitioning actions, so back up any data you want to keep first.

<Note>
  A custom ISO is available for **24 hours** and is then removed. The portal assigns it a filename based on your VPS ID; it may differ from the original filename on your computer.
</Note>
