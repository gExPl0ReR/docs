## Reinstall your VPS with a fresh OS

You can reinstall your Virtual Private Server (VPS) with a clean operating system in just a few clicks.\
Whether you’re switching from Linux to Windows or simply starting fresh, the **Reinstall OS** feature lets you rebuild your VPS quickly and securely.

> ⚠️ **Important:** Reinstalling your VPS will permanently erase all data.\
> Make sure you have backups before proceeding.

## Step-by-step reinstallation

<Steps>
  <Step title="Log in to your control panel">
    Go to your [VPS Management Portal](https://manage.edisglobal.com/clientarea.php) and open **Services → My Services**.
  </Step>
  <Step title="Locate your VPS">
    Select the VPS you want to reinstall.
  </Step>
  <Step title="Click “Reinstall OS”">
    Select the operating-system family, then its version. Review the optional SSH public-key field where available and set a new password.\
    This will be your Linux **root** or Windows **Administrator** password.

    > ⚠️ **Note:** EDIS Global doesn't send a confirmation email when you reinstall. Keep your new password safe!
  </Step>
  <Step title="Start installation">
    Once you have checked the selected VPS, saved your new password and backed up your data, click **Start installation**. Wait for the process to finish before reconnecting.
  </Step>
</Steps>

## Installation time and port behavior

Allow the automated setup to finish before connecting. Typical installation times are:

<Columns cols={2}>
  <Card title="Linux" icon="terminal">
    <div style={{ display: "flex", alignItems: "baseline", gap: "8px", margin: "8px 0 16px" }}>
      <span style={{ fontSize: "2.5rem", lineHeight: 1.1, fontWeight: 700, color: "#F96002" }}>≈ 5</span>
      <span>minutes</span>
    </div>

    **SSH · TCP port 22**

    Unavailable during installation.
  </Card>
  <Card title="Windows" icon="desktop">
    <div style={{ display: "flex", alignItems: "baseline", gap: "8px", margin: "8px 0 16px" }}>
      <span style={{ fontSize: "2.5rem", lineHeight: 1.1, fontWeight: 700, color: "#F96002" }}>≈ 15</span>
      <span>minutes</span>
    </div>

    **Remote Desktop · TCP port 3389**

    Unavailable during installation.
  </Card>
</Columns>

These times are approximate. SSH or RDP being unavailable while setup runs is expected and does not, by itself, mean the installation has failed.

<Warning>
  **Do not power off, reboot, or start another reinstall while installation is in progress.** Interrupting setup can leave the operating system incomplete.
</Warning>

Once setup finishes, connect using [SSH for Linux](/getting-started/linux-secure-shell-ssh) or [Remote Desktop for Windows](/getting-started/windows-remote-desktop), with the password you chose during reinstallation. EDIS Global doesn't send a new credentials email.

<Tip>
  Reinstalling Linux can change its SSH host key. If your client reports **“REMOTE HOST IDENTIFICATION HAS CHANGED”**, follow the [host-key verification steps](/getting-started/linux-secure-shell-ssh#remote-host-identification-has-changed) before accepting the new key.
</Tip>

## Installation via Cloud-Init

If you prefer to use your **own operating system image**, EDIS Global also supports installations via **Cloud-Init**.\
This method is ideal for advanced users who want to **bring their own (BYO) image**, such as a custom or pre-built `.qcow2` file. Cloud-Init user-data then configures the image automatically on first boot.

<Note>
  Use **Cloud-Init** when you need to:\
  • deploy a custom or pre-configured operating system image\
  • automate user creation, SSH keys, or initial setup commands\
  • maintain full control over your server’s image and configuration

  If you just need a clean Linux or Windows environment, the **Reinstall OS** option is simpler and faster.
</Note>
