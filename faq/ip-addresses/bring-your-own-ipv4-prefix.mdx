EDIS Global supports **Bring Your Own IP (BYOIP)** for VPS services.

If you own an IPv4 **/24 or larger** prefix, we can announce and route it through our network, allowing you to use your own IP addresses with your VPS instances.

If you are interested, please **describe your use case** so we can recommend the most suitable integration method.

<Note>
  A separate **/24 (or larger)** IPv4 prefix is required for **each server location** where you want to use your own IP space.

  Example:

  - Cyprus → one /24
  - Frankfurt → another /24
  - New York → another /24
</Note>

## Integration options

We offer two different integration models.

### Full integration (recommended)

Your IP range becomes fully integrated into the EDIS Global platform.

With this option:

- Every newly ordered VPS in the agreed location automatically receives an IPv4 address from **your** IP range.
- Up to **10 additional IPv4 addresses** from your own range can be assigned to a single VPS.
- IP address changes continue to use addresses from your own prefix only.
- Automatic IP configuration during OS reinstall is supported (depending on the operating system).
- Reverse DNS (rDNS/PTR) management is available through the customer portal.
- Your IP addresses are fully integrated into our provisioning and management systems, including spoofing protection and duplicate IP address assignment protection.

This option provides the same user experience as using standard EDIS Global IPv4 addresses while retaining ownership of your address space.

### Partial integration

This option offers maximum flexibility with minimal platform integration.

With this option:

- Every new VPS is delivered with a standard EDIS Global IPv4 address.
- Your announced IPv4 prefix is whitelisted in our anti-spoofing protection.
- You may configure **any number of your own IP addresses** inside your VPS within the agreed location (might be interesting for proxy providers).
- You are responsible for managing IP addresses and avoiding duplicate IP assignments.
- Your IP addresses are **not** stored in our management databases.
- Your own IP addresses are **not** displayed in the customer portal.
- Automatic IP configuration during OS reinstall is **not** available.
- Reverse DNS (rDNS/PTR) management for your own IP addresses is **not** available.

This option is ideal if you prefer to manage your IP space entirely yourself and you want the flexibility to freely move IP addresses between VPS and require more than 10 additional IP addresses inside one VPS.

## Setup fee

A **one-time setup fee of EUR 199** applies **for each announcement request in each server location**, regardless of the number of IPv4 prefixes announced as part of that request.

Multiple prefixes announced together in a single request incur only **one** setup fee. Any future announcement requests for the same location are charged separately.

### Examples

| Announcement | Setup fee |
| --- | --- |
| 1 × /24 in Cyprus | EUR 199 |
| 5 × /24 in Cyprus | EUR 199 |
| 3 × /24 in Cyprus \+ 2 × /24 in Frankfurt | EUR 398 |

## Requirements

- You must own the IPv4 prefix or have the legal right to use it.
- The prefix must be registered with a Regional Internet Registry (RIR).
- You must provide authorization for us to announce the prefix on your behalf (e.g. an LOA and/or appropriate RPKI ROA, depending on your routing setup).
- The minimum supported prefix size is **/24**.
- Larger prefixes are also supported.
- A separate **/24 (or larger)** prefix is required for each server location where you want to use BYOIP.
- The prefix will be announced under **your own Autonomous System (AS) number**.
