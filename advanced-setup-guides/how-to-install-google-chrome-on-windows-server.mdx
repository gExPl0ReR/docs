After activating a VPS with Windows, one of the first tasks is often to install a web browser like Google Chrome. This guide provides a detailed, step-by-step process for installing Google Chrome on your rented Windows Server VPS, ensuring you have a secure and efficient browsing experience right from the start.

## How to get going 

1. [Order a VPS](https://www.edisglobal.com/) with pre-installed Windows Server OS.
2. [Connect to the server via RDP](../getting-started/windows-remote-desktop), port 3389.
3. Open the **Server Manager**. The Server Manager usually opens automatically when the operating system starts. However, if the Server Manager does not open automatically, click the **Start** button. Then, find and select "**Server Manager**" in the **Start** menu. It is typically pinned by default when you install Windows Server.
![Install Chrome on Windows Server](/assets/y9B0AGVAxYeSyeZVyaDis-7QVfnkzj8whiU7FU1x-GV-20240925-111932.png)
4. Select the **Local Server** section in the Server Manager
![Install Chrome on Windows Server](/assets/y9B0AGVAxYeSyeZVyaDis-6mlwvxUHmMw4B2Uhjy3fx-20240925-112129.png)
5. Disable the IE Enhanced Security Configuration setting by clicking on "On":
![Install Chrome on Windows Server](/assets/y9B0AGVAxYeSyeZVyaDis-ZadLaSIVTwxMBR9WJxb-X-20240925-112756.png)
6. Click the **Run** button on the new pop-up window located in the bottom section of the screen.
![Install Chrome on Windows Server](/assets/y9B0AGVAxYeSyeZVyaDis-T6_8Y4a5mP3LvYEuxojJp-20240925-113951.png)
7. Set Google Chrome as the default browser.
![Install Chrome on Windows Server](/assets/y9B0AGVAxYeSyeZVyaDis-CO7-zXgNq_r2mTA79IpJb-20240925-114316.png)
8. Congratulations! You have successfully installed Google Chrome on your Windows Server. This installation enhances the server's capabilities by providing a fast and secure web browser.
![Install Chrome on Windows Server](/assets/y9B0AGVAxYeSyeZVyaDis-JSmf__3EKINSsSxUUMSsU-20240925-114409.png)
