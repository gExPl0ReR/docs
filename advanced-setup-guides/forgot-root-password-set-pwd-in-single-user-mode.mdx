<Info>
  For current EDIS Global VPS installations, start with [Reset a Linux root password](/vps-management/reset-root-password-linux). The screenshots and `e` → `e` → `b` key sequence below show **legacy GRUB**, not the GRUB 2 interface used by many current distributions. Recovery-mode authentication also varies by distribution; single-user mode does not always bypass a password prompt.
</Info>

## Set a new password by booting your Linux VPS in single-user mode

A password change inside Linux is separate from signing in to the VPS Management Portal. If you use this legacy recovery method, follow the procedure for your distribution and bootloader.

Follow these easy steps if you no longer have access to your Linux operating system, and you need to set a fresh Linux root password on your KVM.

<Steps>
  <Step title='Start by enabling VNC'>
    [KVM-Panel](https://manage.edisglobal.com/clientarea.php)

    VNC gives you "remote access to your server's keyboard and screen".
    
    ![Reset Linux Root Password (Single-User Mode)](/assets/F8eNYsykWzRS62iS3P4Us_edis-vnc-novnc.gif)

  </Step>
  <Step title='Launch noVNC session' />
  <Step title='Reboot your VPS' />
  <Step title='Enter the Grub (boot loader) menu'>
    When the following screen appears, press any key to enter the Grub (boot loader) menu.

    ![Reset Linux Root Password (Single-User Mode)](/assets/Fvrm2wZksE9VQ7RLz4dUW_grub-13e81545cf.png)

  </Step>
  <Step title='Press `e` on your keyboard to edit the kernel boot options.'>
    ![Reset Linux Root Password (Single-User Mode)](/assets/PDn-VLEH4oY9Ts5aMWFtt_grub-menu-02a3c5087e.png)
  </Step>
  <Step title='Highlight the second stanza (line) and press `e` again.'>
    ![Reset Linux Root Password (Single-User Mode)](/assets/UupFVGCUzqwNZuW7v-njE_grub-edit-1-a6217c96fc.png)
  </Step>
  <Step title='Edit the line highlighted in the previous step'>
    You can now edit the line highlighted in the previous step. Add `1` at the end of the line as indicated in the following screenshot, then confirm by pressing `Enter`.

    On Debian, add `init=/bin/bash` instead of `1` at the end of the line.
    
    ![Reset Linux Root Password (Single-User Mode)](/assets/dmeyDtDBPFyQZjL7_rrMm_grub-edit-2-1a8c865f73.png)

  </Step>
  <Step title='Now you see the Grub stanzas as shown in step 5'>

    Press `b` to continue booting, using the modified configuration. Linux now boots into single-user mode, which allows special administrative tasks. A recovery shell must have access to the root filesystem and permission to modify it before you can set a new password. Once the system is up and running, type the following command to update the root password:
    
    ```shell
    passwd root
    ```
    
    The system prompts you to enter a new password for the root user.

  </Step>
  <Step title='Once finished, reboot your VPS and you will be able to use the newly set root password' />
</Steps>
