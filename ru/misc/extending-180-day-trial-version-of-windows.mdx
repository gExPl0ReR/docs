## Как продлить ознакомительный период Windows {#how-to-extend-your-windows-trial}

Ознакомительные редакции Windows Server работают **180 дней**. Когда этот срок подходит к концу, его можно продлить простой командой.

> **Полезно знать:** Microsoft разрешает **ограниченное число продлений («rearm»)** для ознакомительных редакций. Команда ниже работает только при наличии оставшихся продлений. В большинстве редакций её можно выполнить до пяти раз: всего получается около **шести периодов по 180 дней, то есть почти три года** тестирования.

### 1) Проверьте текущее состояние лицензии {#1-check-your-current-license-status}

Откройте **PowerShell от имени администратора** и выполните:

```powershell
slmgr -dlv
```

### 2) Продлите ознакомительный период (добавьте 180 дней) {#2-extend-the-trial-add-180-days}

Когда срок подходит к концу или в другое удобное время, выполните:

```powershell
slmgr -rearm
```

### 3) Перезагрузите сервер {#3-restart-the-server}

Чтобы изменение вступило в силу, перезагрузите систему:

```powershell
Restart-Computer
```

После перезагрузки ознакомительный период будет продлён ещё на 180 дней.

### Законно ли продлевать ознакомительную версию Windows? {#is-it-legal-to-extend-a-trial-version-of-windows}

Команда **slmgr -rearm** для продления ознакомительного периода Windows Server — функция, которую Microsoft предоставляет для определённых редакций своего ПО, прежде всего для ознакомления и оценки. Она сбрасывает таймер активации и может использоваться ограниченное число раз, чтобы продлить ознакомительный период. Обычно это даёт дополнительное время для оценки продукта перед покупкой лицензии.

Однако законность и добросовестность использования этой функции зависят от условий лицензионного соглашения Microsoft (Software License Agreement, SLA), которое вы приняли при первой установке или использовании ПО. Соглашения для редакций Windows Server с такой функцией обычно разрешают ограниченное число сбросов ознакомительного периода именно для тестирования и оценки.

Хотя технически **slmgr -rearm** позволяет продлить ознакомительный период, необходимо:

1. **Соблюдать ограничения**, установленные Microsoft: обычно не более двух раз, с продлением максимум на дополнительные 180 дней.
2. **Понимать, что функция предназначена для оценки**, а не для постоянного отказа от покупки необходимых лицензий при длительном использовании.

Если вы используете ПО в коммерческой среде или для любых целей, кроме оценки, рекомендуем приобрести действительную лицензию. Это позволит соблюдать лицензионные условия Microsoft и избежать правовых проблем.

Всегда обращайтесь к конкретному SLA для вашей версии Windows Server. При необходимости получите консультацию юриста или специалистов Microsoft по лицензированию с учётом вашей ситуации.
