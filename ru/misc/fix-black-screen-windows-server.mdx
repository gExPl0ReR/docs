## Устранение чёрного экрана при подключении к Windows Server {#fix-black-screen-when-connecting-to-windows-server}

Чёрный экран без курсора при подключении к Windows Server через удалённый рабочий стол (RDP) мешает работе. В этом руководстве предложены два возможных решения: изменение реестра Windows и использование другого RDP-клиента.

***

## Проблема: чёрный экран после подключения через удалённый рабочий стол (RDP) {#issue-black-screen-after-connecting-via-remote-desktop-rdp}

При подключении к Windows Server по RDP может появиться чёрный экран без видимого указателя мыши. Частая причина — несовпадение настроек RDP-клиента и сервера.

***

## Решение 1. Изменение реестра Windows {#solution-1-modify-the-windows-registry}

Изменение определённого параметра реестра может устранить проблему.

### Измените локальный реестр на своём ПК и перезагрузите систему {#modify-the-local-registry-on-your-pc-then-reboot-the-system}

1. **Откройте командную строку**:

   * Нажмите `Win + R`, чтобы открыть окно **Run** («Выполнить»).

   * Введите `cmd` и нажмите **Enter**.

2. **Выполните команду изменения реестра**: скопируйте следующую команду в командную строку и нажмите **Enter**:

```powershell
reg add "HKLM\SOFTWARE\Microsoft\Terminal Server Client" /v "UseURCP" /t REG_DWORD /d 0 /f
```

**Перезагрузите локальную Windows**

После выполнения команды перезагрузите свой компьютер.
Затем повторите подключение по RDP и проверьте, исчез ли чёрный экран.

## Решение 2. Использование другого RDP-клиента {#solution-2-use-alternative-rdp-clients}

Если предложенное исправление не помогло, попробуйте подключиться к Windows Server другим клиентом удалённого рабочего стола. Это может позволить обойти проблему стандартного RDP-клиента.

   MobaXterm — универсальный терминальный клиент для Windows с сервером X11, SSH-клиентом с вкладками, сетевыми инструментами и другими функциями.

2. **Parallels RAS**:

   Parallels RAS — комплексное решение для предоставления виртуальных приложений и рабочих столов, позволяющее сотрудникам работать с приложениями и данными с любого устройства.

3. **mRemoteNG**:
   Скачать: [mRemoteNG](https://mremoteng.org/download)
   mRemoteNG — менеджер удалённых подключений с открытым исходным кодом, поддержкой нескольких протоколов и вкладками. Он позволяет управлять всеми удалёнными подключениями в простом и функциональном интерфейсе.

Скачав и установив одну из этих программ, попробуйте подключиться к Windows Server выбранным клиентом. Это может помочь обойти чёрный экран, возникающий в стандартном RDP-клиенте. Если проблема сохраняется, обратитесь к администратору сервера или в ИТ-отдел, чтобы проверить, нет ли причин на стороне сервера.
