<Update label="Март 2025">
  ## Описание тарифа в Order API теперь использует структурированный объект {#plan-description-field-in-order-api-now-uses-structured-object-format}

  Поле описания тарифа в Order API изменено: вместо одной неструктурированной HTML-строки теперь используется структурированный машиночитаемый объект. Данные отделены от представления, поэтому их проще разбирать, локализовать и единообразно отображать в разных интерфейсах.

  ---

  **🧾 Раньше**

  ```php
  [KVM DIAMOND] => stdClass Object
  (
      [id] => 1834
      [description] => "8192 MB RAM 1 CPU core 100 GB SSD ... <strong>30 TB Traffic</strong> ..."
  )
  ```

  • Описание представляет собой **одну HTML-строку**.

  • Оно предназначено для непосредственного отображения на веб-странице.

  • Для извлечения значений, например RAM или CPU, нужны регулярные выражения или ручной разбор.

  • Его сложно локализовать или преобразовывать программно.

  • Данные смешаны с оформлением (\<br /\>, \<strong\>).

  ---

  ✅ **Теперь**

  ```php
  [KVM DIAMOND] => stdClass Object
  (
      [id] => 1834
      [description] => stdClass Object
          (
              [disk] => stdClass Object
                  (
                      [size] => 100
                      [unit] => GByte
                  )
              [ram] => stdClass Object
                  (
                      [size] => 8192
                      [unit] => MByte
                  )
              ...
          )
  )
  ```

  • Описание теперь является **вложенным структурированным объектом**.

  • Значения и единицы измерения чётко разделены: size, unit.

  • Значительно проще выполнять сортировку, фильтрацию и проверку.

  • Данные можно динамически отображать в разных форматах: HTML, обычный текст, JSON.

  • Можно переводить единицы измерения и локализовать данные для разных языков.

  • **Логику отображения можно реализовать отдельно** — в шаблонах интерфейса, средствах отображения Markdown и т. п.

  ---

  **💡 Преимущества изменения**

  • ✅ Проще поддерживать и обновлять.

  • ✅ Поддерживается интернационализация.

  • ✅ Доступна фильтрация, например «тарифы с ≥16 GB RAM».

  • ✅ Исходные данные остаются чистыми и пригодными для повторного использования.
</Update>
