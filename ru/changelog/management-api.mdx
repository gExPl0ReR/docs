## История изменений Management API

Обновления и улучшения

<Update label="Март 2025">

  <span id="dns-api-domain-update" />

  #### Обновление домена DNS API

  Мы добавили новую кластеризованную конечную точку DNS API:

  - **Новое имя хоста DNS API:** dns-api.edisglobal.com
  - Изменение отражает переход от **EDIS GmbH** к **EDIS Global** и обеспечивает единообразие даже в самых удалённых частях инфраструктуры.

  Прежняя конечная точка dns-api.edis.at останется активной для обратной совместимости, но во всех будущих сообщениях будет использоваться dns-api.edisglobal.com.

  **Дополнительно:**

  Новый dns-api.edisglobal.com теперь **работает в кластере**, что повышает резервирование и надёжность.

</Update>
