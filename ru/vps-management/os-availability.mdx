## Доступность операционных систем {#operating-system-availability}

EDIS Global предлагает широкий выбор операционных систем для VPS.\
При этом список образов ОС **при первоначальном заказе** намеренно отличается от списка, доступного позднее в **панели управления (Auto-Installation)**.

Это руководство объясняет различия и помогает выбрать подходящую ОС.

## Почему списки различаются? {#why-are-the-lists-different}

### Корзина: рекомендуемые варианты {#shopping-cart-=-recommended-defaults}

Упрощённый список исключает:

- Очень старые или устаревшие версии ОС
- Узкоспециализированные или сложные конфигурации
- Повторяющиеся варианты, которые могут запутать
- Старые поколения LTS, которые больше не рекомендуются

Это упрощает начало работы новым пользователям.

---

### Панель управления VPS: полная гибкость {#vps-control-panel-=-full-flexibility}

В панели доступны **все образы автоматической установки**, включая:

- Старые шаблоны, которые ещё нужны существующим клиентам
- Старые выпуски LTS
- Дополнительные сборки и снимки
- Расширенные варианты ОС
- Устаревшие версии, сохранённые для совместимости

Это позволяет опытным пользователям полностью контролировать свою среду.

## Установочные ISO и носители восстановления {#iso-installation-and-recovery-media}

ISO-носители отличаются от перечисленных выше образов Auto-Install. Установочный ISO позволяет вручную установить совместимую ОС через консоль VNC. Носители восстановления загружают временную среду для диагностики существующей системы или сброса пароля.

Перечень ниже проверен **10 сентября 2026 года**. В списке **Mount ISO** панели VPS показаны носители, доступные для вашего сервера сейчас.

### Установочные ISO {#installation-isos}

| Операционная система или программный комплекс | Имя ISO-файла | Назначение |
| --- | --- | --- |
| Kali Linux 2021.1 | `Kali-linux-2021.1-installer-netinst-amd64.iso` | Ручная сетевая установка Kali Linux. |
| Linux Mint 20.3 Xfce | `LinuxMint-20.3-Desktop-xfce-64bit.iso` | Ручная установка Linux Mint с рабочим столом Xfce. |
| MikroTik RouterOS 6.48.6 | `MikroTik-RouterOS-6.48.6.iso` | Ручная установка RouterOS. |
| MikroTik RouterOS 7.2 | `MikroTik-RouterOS-7.2.iso` | Ручная установка RouterOS. |
| pfSense 2.7 | `pfSense-2.7.iso` | Ручная установка системы межсетевого экрана / маршрутизатора. |
| Windows Server 2016 Evaluation | `Windows_Server_2016_RS1_EVAL_x64_ENG.iso` | Ручная установка ознакомительной версии Windows Server. |
| Windows Server 2019 Evaluation | `Windows_Server_2019_RS5_EVAL_x64_EN-US.iso` | Ручная установка ознакомительной версии Windows Server. |
| Windows Server 2022 Evaluation | `Windows_Server_2022_EVAL_x64_EN-US.iso` | Ручная установка ознакомительной версии Windows Server. |

Это носители конкретных версий, включая старые выпуски, сохранённые для совместимости. Наличие в списке не означает, что версия является последней или ещё получает обычные обновления безопасности от поставщика. Для новой рабочей среды проверьте сроки поддержки поставщика и требования приложения. Если нужен другой выпуск, можно [предоставить собственный совместимый ISO](/ru/vps-management/bring-your-own-iso).

Windows Server 2016 указан здесь как **вариант ISO**, а не образ Auto-Install. Ознакомительные носители Windows не включают платную лицензию Windows. Вы отвечаете за лицензии, необходимые вашей ОС и приложениям.

Для нового развёртывания MikroTik CHR наш [автоматический установщик MikroTik](https://docs.edisglobal.com/advanced-setup-guides/script-based-mikrotik-router-os-installation-guide-winbox) автоматически скачивает **последний стабильный выпуск RouterOS v7, доступный у MikroTik на момент установки**. Перечисленные выше ISO RouterOS 6.48.6 и 7.2 — носители фиксированных версий для ручной установки; они не ограничивают версию, устанавливаемую скриптом. Выберите подходящий образ и модель лицензирования для своей задачи.

### Инструменты восстановления {#recovery-tools}

| Инструмент восстановления | Имя ISO-файла | Когда использовать |
| --- | --- | --- |
| SystemRescue 10.02 (AMD64) | `0_SystemRescue-10.02-amd64.iso` | Загрузите среду восстановления для проверки дисков или диагностики Linux, который не загружается или не принимает подключения. См. [руководство по восстановлению Linux](/ru/vps-management/linux-rescue-guide-and-troubleshoot). |
| Password Reset Helper | `1_Password-Reset-Helper.iso` | Сбросьте [пароль Administrator в Windows](/ru/vps-management/reset-windows-admin-password) или [пароль root в Linux](/ru/vps-management/reset-root-password-linux). Следуйте инструкции для своей операционной системы. |

Инструменты восстановления используются с существующим VPS и не заменяют установленную ОС. Следуйте соответствующему руководству и не форматируйте диск и не переустанавливайте систему, если цель — восстановить существующую установку. После восстановления отключите ISO и загрузитесь с диска VPS.

### Как использовать ISO {#how-to-use-an-iso}

1. Сохраните необходимые данные перед установкой или изменением разделов диска. Ручная установка ОС может перезаписать существующую систему и её данные.
2. Откройте VPS в [панели управления VPS](https://manage.edisglobal.com), нажмите **Mount ISO** и выберите нужный носитель. Следуйте [инструкции по подключению ISO](/ru/vps-management/mount-iso-image) для загрузки с него.
3. Откройте [консоль VNC](/ru/vps-management/enable-vnc-server) и следуйте указаниям установщика или соответствующей процедуре восстановления. Проверьте требования ОС к оборудованию, режиму загрузки и драйверам.
4. По завершении отключите ISO и перезапустите VPS с его диска.

Носители драйверов, например драйверы VirtIO для установки Windows, помогают в процессе установки, но не являются установщиками ОС или средами восстановления.
