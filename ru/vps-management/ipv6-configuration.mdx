## Как выделяются IPv6-адреса {#understand-your-ipv6-allocation}

Каждый VPS EDIS Global получает собственный **диапазон IPv6 размером, эквивалентным /64**. Он принадлежит этому VPS, но **не маршрутизируется как отдельная подсеть /64**.

Каждая серверная локация EDIS Global работает в общей сети IPv6 `/48` и имеет собственный шлюз по умолчанию. Для доступа к этому шлюзу настраивайте каждый IPv6-адрес VPS с **длиной префикса `/48`**.

| Параметр | Значение |
| --- | --- |
| Диапазон на VPS | Эквивалент `/64` |
| Отдельно маршрутизируемая подсеть | Нет |
| Длина префикса в настройках VPS | `/48` |
| Максимум активных IPv6-адресов | 20 |
| Шлюз по умолчанию | Зависит от локации |

<Warning>
  Настройка адреса с `/48` не выделяет вашему VPS всю сеть `/48` локации. Используйте только адреса из диапазона, назначенного вашему VPS.
</Warning>

При развёртывании мы обычно настраиваем один IPv6-адрес. Выделенный диапазон и точный шлюз локации указаны в приветственном письме и в **Network Info** [панели управления VPS](/ru/vps-management/ip-address-information).

## Настройте IPv6-адрес в Linux {#configure-an-ipv6-address-on-linux}

Постоянная сетевая конфигурация зависит от ОС. В Debian и других Linux-системах адрес можно проверить во время работы командой `ip`.

В командах ниже используются примеры. Замените адрес, шлюз и интерфейс значениями для вашего VPS.

Добавьте IPv6-адрес:

```bash
ip -6 addr add 2a03:f80:ed15:435a::1/48 dev eth0
```

Покажите настроенные IPv6-адреса:

```bash
ip -6 addr show
```

Одновременно можно настроить до **20 постоянных IPv6-адресов** из выделенного VPS диапазона.

## Настройте маршрут IPv6 по умолчанию {#configure-the-ipv6-default-route}

Добавьте шлюз по умолчанию для локации:

```bash
ip -6 route add default via 2a03:f80:ed15::1 dev eth0
```

Покажите настроенный маршрут:

```bash
ip -6 route show
```

<Note>
  У каждой серверной локации свой шлюз IPv6. Всегда используйте точный шлюз из панели VPS или приветственного письма; не вычисляйте и не угадывайте его по приведённому примеру.
</Note>

<Tip>
  **IPv6-адрес настроен, но недоступен?** Попробуйте отправить ping шлюзу с этого IPv6-адреса. Это может помочь маршрутизатору добавить адрес в кеш Neighbor Discovery.

  ```bash
  ping -6 -c 1 -I 2a03:f80:ed15:435a::1 2a03:f80:ed15::1
  ```

  Замените адрес после `-I` IPv6-адресом, уже настроенным на VPS, а последний адрес — точным шлюзом своей локации. Повторите для каждого недоступного адреса, затем проверьте доступность с внешнего IPv6-хоста. Ping с одного адреса не обязательно сделает доступными остальные настроенные адреса.
</Tip>

## Ограничения использования IPv6 {#ipv6-usage-restrictions}

Запрещены IPv6-прокси, которые сменяют адреса, автоматически генерируют случайные адреса или перебирают большое количество адресов. Одновременная настройка более 20 IPv6-адресов может перегрузить кеш IPv6 Neighbor Discovery.

Нарушения приводят к приостановке услуги. Повторные нарушения приводят к окончательному закрытию аккаунта без возврата средств. См. [Правила допустимого использования](/ru/getting-started/acceptable-use-policy).

Если после проверки этих настроек IPv6 остаётся недоступным, перейдите к [диагностике IPv6](/ru/vps-management/basic-ipv6-troubleshooting).
