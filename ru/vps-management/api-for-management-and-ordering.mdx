# API для управления VPS и оформления заказов {#vps-api-for-management-and-ordering}

**API EDIS Global** позволяют полностью автоматизировать жизненный цикл VPS: от развёртывания и настройки до увеличения ресурсов, управления трафиком и прекращения услуг.  
Используйте их, чтобы интегрировать управление EDIS VPS в свои системы, панели управления и процессы автоматизации.

---

## 🚀 API управления VPS {#-vps-management-api}

Управляйте всеми аспектами своей VPS-инфраструктуры.

**Основные возможности:**

- Управление питанием: запуск, остановка, перезагрузка
- Настройка обратного DNS (rDNS/PTR)
- Установка ОС и загрузка ISO
- Доступ к консоли VNC и снимкам экрана
- Операции с Traffic Pool и вебхуки

🔗 [**Открыть справочник Management API →**](https://docs.edisglobal.com/management-api-reference/authentication/create-auth-session)

---

## 📦 API заказов VPS {#-vps-order-api}

Автоматизируйте создание VPS, смену тарифов и отмену услуг.

**Основные возможности:**

- Настройка и заказ VPS в любой локации EDIS Global
- Переход на более мощные тарифы и покупка дополнений
- Отмена или изменение существующих услуг
- Программное получение сведений о заказах и оплате

🔗 [**Открыть справочник Order API →**](https://docs.edisglobal.com/order-api-reference/order-api-welcome)

---

## 🔐 Аутентификация и интеграция {#-authentication-&-integration}

У двух API разные требования к доступу и аутентификации:

| API | Доступ | Аутентификация |
| --- | --- | --- |
| **Order API** | Доступен после регистрации при условии стандартной проверки аккаунта. Отдельная регистрация в качестве реселлера или ручная активация не требуются. | Email и пароль личного кабинета (`email`, `pw`), без отдельно выдаваемого API-токена. |
| **Management API** | В аккаунте должен быть хотя бы один VPS. | Создайте сессию с помощью email и пароля, затем используйте полученные значения сессии, включая `signature`, `valid_until` и `kvm_id`. |

Двухфакторная аутентификация применяется при входе в панель управления; API не требуют код 2FA. Храните учётные данные и значения сессий в секрете на серверной стороне своей интеграции.

Сейчас ограничения количества API-запросов не применяются, однако их объём должен оставаться разумным. Избегайте чрезмерно частых опросов и согласовывайте массовое развёртывание со службой поддержки.

Начните с раздела [Перед автоматизацией](/order-api-reference/order-api#before-you-automate): в нём описаны проверка наличия ресурсов, оплата, создание VPS, Cloud-Init и обработка неопределённых результатов заказа. Текущие API работают с реальными услугами; тестовой среды для заказов нет.

> За рекомендациями по реализации или сложным сценариям интеграции обращайтесь в **службу поддержки EDIS Global**.
