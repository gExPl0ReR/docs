## Traceroute и MTR в Windows {#traceroute-and-mtr-on-windows}

Если между домашним интернетом и VPS наблюдаются потери пакетов или медленное соединение, отправьте нам отчёт MTR или TRACEROUTE. Он подробно показывает сетевой путь между вашим подключением и VPS и возможные места потерь.

**Для пользователей Windows**: MTR не входит в Windows по умолчанию, но TRACEROUTE запускается легко.

1. **TRACEROUTE**:
   - Нажмите `Windows + R`, чтобы открыть окно Run.
   - Введите `cmd` и нажмите Enter для запуска командной строки.
   - Введите `tracert [Your VPS IP Address]`, заменив заполнитель IP-адресом своего VPS.
   - Дождитесь завершения: это может занять несколько минут.
   - Нажмите правой кнопкой внутри окна, выберите `Mark`, выделите весь результат и нажмите `Enter` для копирования.
   - Вставьте результат в ответ нам.
2. **MTR**:
   - Для отчёта именно MTR понадобится сторонний инструмент, например WinMTR.
   - Скачайте WinMTR <a href="https://winmtr.net" target="_blank">здесь</a>.
   - Установите и откройте WinMTR.
   - В поле **Host** введите IP VPS.
   - Нажмите **Start** и оставьте тест работать минимум на 5–10 минут для достаточного количества данных.
   - Нажмите **Export TEXT** и сохраните отчёт.
   - Приложите сохранённый отчёт к ответу нам.

Отправьте результаты, и мы оперативно проверим возможную причину и приступим к решению.
