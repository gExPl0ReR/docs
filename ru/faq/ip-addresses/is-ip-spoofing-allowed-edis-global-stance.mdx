## Разрешена ли подмена IP? {#is-ip-spoofing-allowed}

<Warning>
  **Подмена IP-адресов строго запрещена и технически невозможна в нашей сети.** EDIS Global применяет несколько мер для предотвращения IP spoofing.
</Warning>

### Что такое IP spoofing? {#what-is-ip-spoofing}

IP spoofing — изменение исходного IP-адреса в заголовке IP-пакета. Цель — создать впечатление, что пакет пришёл из другого источника. Этот обманный приём может использоваться в разных вредоносных целях.

### Опасности и риски {#dangers-and-concerns}

Подмена IP подрывает доверие и целостность сетевого обмена и создаёт серьёзные риски безопасности. Она может быть частью более крупных атак, использоваться для обмана пользователей и обхода систем защиты.
