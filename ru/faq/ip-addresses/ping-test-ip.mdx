## Проверьте соединение с инфраструктурой EDIS Global {#test-connectivity-to-edis-global-infrastructure}

Хотите проверить нашу сеть перед покупкой VPS? Конечно.

EDIS Global предоставляет инструменты для **оценки производительности сети, маршрутизации и задержки** перед выбором локации сервера.

Они помогают определить, какая локация VPS обеспечивает **лучшее соединение из вашей сети**.

---

## IP-адреса шлюзов, доступные для ping {#pingable-gateway-ip-addresses}

Мы предоставляем список **IP-адресов шлюзов, отвечающих на ping**, в нашей инфраструктуре, чтобы вы могли проверить соединение из своего местоположения.

👉 **Открыть список:**\
http://manage.edisglobal.com/stgfefew_net_list.php

⚠️ Обратите внимание:\
Не все перечисленные IP-диапазоны всегда доступны для создания VPS. Список служит **общим ориентиром для проверки соединения**.

Если вы нашли локацию и диапазон с хорошими результатами, наша команда может подтвердить **наличие ресурсов для развёртывания VPS**.

## Бесплатный тест задержки {#free-latency-test}

**Free Latency Test** измеряет задержку от вашего устройства до **локаций VPS EDIS Global по всему миру**.

👉 **Запустить тест задержки:**\
https://www.edisglobal.com/free-latency-test

Инструмент помогает:

- определить **ближайшие локации VPS**;
- сравнить **задержку в разных регионах**;
- оценить **отзывчивость сети**.

Результаты также включают **индикатор Ping Feel**, который переводит численные значения задержки в простое описание ощущаемой отзывчивости соединения.

## Серверы Looking Glass {#looking-glass-servers}

Наши **серверы Looking Glass** позволяют выполнять более глубокую диагностику сети.

👉 **Открыть список серверов Looking Glass:**\
https://www.edisglobal.com/blog/looking-glass#list-of-our-worldwide-looking-glass-servers

Каждая страница Looking Glass предоставляет:

- тесты ping для IPv4 и IPv6;
- traceroute / MTR;
- тестовые IP-адреса;
- **файлы для проверки скорости**, доступные для скачивания.

Эти инструменты помогают анализировать **маршруты, потери пакетов и производительность сети**.

## Совет {#tip}

Лучшая локация VPS обычно имеет:

- минимальную задержку;
- стабильную маршрутизацию;
- хорошие пиринговые соединения.

Она не обязательно является ближайшей географически.
