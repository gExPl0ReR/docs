## Введение в ядра CPU {#introduction-to-cpu-cores}

Понимание процессорных ресурсов Linux помогает оптимизировать производительность. Ядра CPU — основные вычислительные единицы VPS; каждое может независимо выполнять инструкции и обрабатывать задачи. Количество ядер напрямую влияет на многозадачность и эффективность обработки нагрузки.

## Проверка количества ядер, доступных Linux {#verifying-the-number-of-cores-available-to-linux}

Для оптимизации Linux VPS важно знать его ресурсы, включая количество ядер CPU. Чем больше ядер, тем больше задач VPS может обрабатывать одновременно. Ниже описано, как проверить их число.

### Файл `/proc/cpuinfo` {#the-/proc/cpuinfo-file}

Один из самых простых способов — прочитать `/proc/cpuinfo`.

**Команда:**

```shell Shell
cat /proc/cpuinfo | grep "processor"
```

Вывод содержит строку для каждого ядра; файл также предоставляет сведения, например модель процессора. Каждая строка `processor` представляет ядро CPU. Посчитайте такие строки, чтобы узнать общее количество.

### Команда `lscpu` {#the-lscpu-command}

`lscpu` выводит подробные сведения об архитектуре CPU.

**Команда:**

```shell Shell
lscpu
```

Найдите строку `CPU(s)` с общим количеством ядер. Чтобы различить физические ядра и потоки при hyper-threading, смотрите `Core(s) per socket` и `Thread(s) per core`.

### Команда `nproc` {#the-nproc-command}

Для простого подсчёта доступных вычислительных единиц используйте **nproc**.

**Команда:**

```shell Shell
nproc
```

Она возвращает одно число — количество ядер CPU.

### Команды `top` и `htop` {#the-top-and-htop-commands}

`top` и `htop` — интерактивные средства просмотра процессов и текущего состояния системы.

**Использование top:**

**Команда:**

```shell Shell
top
```

После запуска смотрите раздел Cpu(s): он показывает статистику загрузки ядер.

**Использование htop:**

**Команда:**

```shell Shell
htop
```

В верхней части интерфейса `htop` загрузка каждого ядра показана наглядно.

### Команда `hwinfo` {#the-hwinfo-command}

`hwinfo` предоставляет подробные сведения об оборудовании, включая процессоры.

**Команда для сведений о CPU:**

```shell Shell
hwinfo --cpu
```

Количество ядер CPU указано в `Number of processors`.

### Заключение {#conclusion}

Регулярная проверка количества ядер и их загрузки помогает оптимизировать производительность и распределение задач на Linux VPS. Выбирайте методы в зависимости от задачи и установленных утилит.
