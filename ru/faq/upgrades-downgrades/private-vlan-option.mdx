## Добавление частной сети к VPS: Private VLAN Option {#add-a-private-network-to-your-vps-private-vlan-option}

## Что такое Private VLAN? {#what-is-a-private-vlan}

**Private VLAN** позволяет создать частное защищённое Ethernet-соединение между виртуальными серверами (VPS) в одной выбранной локации. Это улучшает сегментацию и безопасность сети и обеспечивает эффективное внутреннее взаимодействие между VPS.

### Основные возможности {#key-features}

- **Второй Ethernet-интерфейс:** каждый VPS в выбранной локации получает дополнительный сетевой интерфейс.
- **Изоляция VLAN:** уникальный VLAN ID позволяет взаимодействовать в настроенной частной сети только VPS, назначенным в одну VLAN.

## Требования {#requirements}

### Использование с одним VPS {#single-vps-use-case}

- Если нужен только **второй Ethernet-интерфейс**, достаточно одного VPS.

### Использование с несколькими VPS {#multiple-vps-use-case}

- Для **частного соединения между VPS** нужны **как минимум два VPS** в одной локации.
- Можно заказать несколько Private VLAN для **сложных сетевых топологий**, назначая разным группам VPS разные VLAN ID.

## Как заказать Private VLAN {#how-to-order-a-private-vlan}

1. **Выберите локацию:** определите, где нужна Private VLAN.
2. **Закажите Private VLAN Option:** приобретите опцию в магазине:

   [Купить Private VLAN Option](https://manage.edisglobal.com/cart.php?gid=209)
3. **Оплата и активация:** после оплаты счёта мы автоматически активируем Private VLAN для всех VPS в выбранной локации.

## Как назначить VPS в Private VLAN {#how-to-assign-your-vps-to-a-private-vlan}

1. **Войдите в панель управления VPS.**
2. **Нажмите System Configuration.**
3. **Прокрутите до VLAN Settings.**
4. **Выберите VLAN ID** из списка, например 102.
5. **Примените настройки.**
6. **Выключите и снова включите VPS**, чтобы активировать изменения.
7. **Повторите для каждого VPS**, который должен подключаться к Private VLAN.
8. **Настройте частные IP-адреса** на вторых сетевых интерфейсах VPS.

## Преимущества Private VLAN {#benefits-of-using-a-private-vlan}

- **Повышенная безопасность:** трафик Private VLAN изолирован от публичной сети.
- **Без платы за трафик:** данные, передаваемые через Private VLAN, **не учитываются** в месячном лимите.
- **Масштабируемость:** несколько VLAN позволяют строить **гибкие и сложные сети**, подходящие для микросервисов, внутренних баз данных и приложений на нескольких серверах.
