Используйте это руководство, если забыли пароль Administrator в Windows Server или хотите его сбросить. Доступ восстанавливается через портал управления VPS: подключение ISO и командная строка позволяют изменить пароль без переустановки ОС. Это офлайн-восстановление учётной записи, а не установка Windows. Перед изменениями ознакомьтесь с ограничениями восстановления.

<Info>
  Сначала попробуйте более короткое [руководство Password Reset Helper](/ru/vps-management/reset-windows-admin-password). Здесь описан классический метод через установщик Windows. Не продолжайте установку Windows и не форматируйте разделы.
</Info>

### Откройте портал управления VPS {#access-the-vps-management-portal}

1. [Включите доступ VNC](/ru/vps-management/enable-vnc-server).
2. Запустите noVNC или VNC-клиент.
3. Откройте [Mount ISO](/ru/vps-management/mount-iso-image) в разделе Server management.
4. Выберите в списке, например, Windows Server 2019.
5. Отметьте **force reset & boot from the selected ISO** и нажмите **Mount ISO**.

   ![Подключение Windows ISO для сброса пароля](/assets/y9B0AGVAxYeSyeZVyaDis-DxatjGPmiR2xG8ndOaF9S-20241101-112320.png)
6. Откройте вкладку noVNC или VNC-клиент.
7. Нажмите `2` для загрузки с подключённого .iso (DVD/CD), например:

   ![Выбор загрузки с ISO](/assets/y9B0AGVAxYeSyeZVyaDis-tMvaxiQ0tBCI0W1wr32rP-20241031-130806.png)

### Подготовка в установщике Windows {#windows-installation-setup}

1. Дождитесь загрузки установщика и нажмите **Next** в Windows Setup.

   ![Начальный экран Windows Setup](/assets/y9B0AGVAxYeSyeZVyaDis-ycT2XmRTWOrWQgPL0kXyc-20241031-131626.png)
2. Нажмите **Install now** в центре окна.

   ![Кнопка Install now](/assets/y9B0AGVAxYeSyeZVyaDis-HTGm3C2qGalRVKDFuy3yD-20241031-131728.png)
3. Выберите **Windows Server 2019 Standard Evaluation (Desktop Experience)** и нажмите **Next**.

   ![Выбор редакции Windows Server](/assets/y9B0AGVAxYeSyeZVyaDis-YICXsmOM7XzGQ7SpXnO1s-20241031-132012.png)
4. Примите условия лицензии и нажмите **Next**.

   ![Условия лицензии](/assets/y9B0AGVAxYeSyeZVyaDis-G-noNdg1wlidP9tjaf7xh-20241031-132230.png)
5. Выберите **Custom: Install Windows only (advanced)**.

   ![Выбор пользовательского режима](/assets/y9B0AGVAxYeSyeZVyaDis-znga0OgEgGp6uwKBrKdkj-20241031-133036.png)
6. В новом окне нажмите **Load Driver**.

   ![Загрузка драйвера диска](/assets/y9B0AGVAxYeSyeZVyaDis-Tq6_xWg0ljJUlVYozPx91-20241031-133159.png)

### Загрузите драйвер Virtio {#load-the-virtio-driver}

1. В окне Load driver нажмите **Browse**.

   ![Выбор расположения драйвера](/assets/y9B0AGVAxYeSyeZVyaDis-TH-J4qyUO6fL1bhAvhqUD-20241031-133451.png)
2. Выберите диск **virtio-win-0.1.215** с нужными драйверами Virtio.

   ![Диск с драйверами Virtio](/assets/y9B0AGVAxYeSyeZVyaDis-KLVIXu39eNuMF0qJPdbKk-20241101-081206.png)
3. Выберите **viostor → 2k19 → amd64** и нажмите **OK**.

   ![Каталог драйвера viostor](/assets/y9B0AGVAxYeSyeZVyaDis-ANAMMM61k1d1o-st8iXbx-20241101-081331.png)
4. После загрузки драйвера нажмите **Next**.

   ![Загруженный драйвер Virtio](/assets/y9B0AGVAxYeSyeZVyaDis-9KG-3tfJ1vkjz2hS-0zLx-20241101-081504.png)

### Откройте командную строку через Windows Setup {#open-command-prompt-via-windows-setup}

1. *Когда появятся диски, не нажимайте Next! Иначе начнётся переустановка с удалением всех данных.* Нажмите `SHIFT+F10`, чтобы открыть командную строку.

   ![Командная строка установщика](/assets/y9B0AGVAxYeSyeZVyaDis-w5beqKW_Cg4j8WXln5C_g-20241101-081619.png)
2. Введите `diskpart`.

   ![Запуск DiskPart](/assets/y9B0AGVAxYeSyeZVyaDis-nnhRVLCxEnFI5NXvcqn3L-20241101-083003.png)
3. Введите `list volume`. На скриншоте Windows находится на **F:**, но буквы дисков в среде восстановления могут отличаться от обычных. Введите `exit` для выхода из DiskPart и проверьте предполагаемые тома, например `dir F:\Windows\System32`. Подтвердите каталог Windows до продолжения: одного размера раздела недостаточно.

   ![Определение тома Windows](/assets/y9B0AGVAxYeSyeZVyaDis-oQo_Pbq0pzQHCyoOj5YEP-20241101-083347.png)
4. Введите `F:`, чтобы перейти на диск F с Windows в этом примере.

   ![Переход на диск Windows](/assets/y9B0AGVAxYeSyeZVyaDis-XV0UsKVaOa0MCZN42Cfmg-20241101-084241.png)
5. Перейдите командой `cd Windows/System32`, затем сохраните Utilman.exe командой `move Utilman.exe Utilman.exe.bak` и нажмите Enter.

   ![Резервная копия Utilman.exe](/assets/y9B0AGVAxYeSyeZVyaDis-qTjJSM2jg_1orDUXrSZT5-20241101-084905.png)
6. Выполните `copy cmd.exe Utilman.exe`.

   ![Временная замена Utilman.exe](/assets/y9B0AGVAxYeSyeZVyaDis-4Iv_06U_2jhjF4nfFVIWB-20241101-085146.png)

### Сбросьте пароль администратора {#reset-the-administrator-password}

1. Вернитесь в KVM Manager и [отключите ISO Windows Server](/ru/vps-management/mount-iso-image). Убедитесь, что образ отключён, вернитесь в VNC и выполните `wpeutil reboot` для перезапуска VPS.

   ![Перезапуск после отключения ISO](/assets/y9B0AGVAxYeSyeZVyaDis-MXmYyOqoOEmh2v5A2NJZH-20241101-090532.png)
2. После загрузки Windows нажмите **CTRL+ALT+DELETE** для экрана входа. Нажмите значок **Ease of Access** справа внизу: откроется командная строка.

   ![Открытие командной строки на экране входа](/assets/y9B0AGVAxYeSyeZVyaDis-iDNLm_tTogDBYAZPsRk-5-20241101-090939.png)
3. Выполните `net user Administrator newstrongpassword`, где `Administrator` — учётная запись администратора Windows с полным управлением системой, а `newstrongpassword` — новый пароль.

   ![Назначение нового пароля Administrator](/assets/y9B0AGVAxYeSyeZVyaDis-rS5jm0Ev_anhpU8F3pNCW-20241101-091436.png)

### Восстановите исходную функцию Ease of Access {#revert-the-changes-to-ease-of-access}

1. Закройте консоль и подключитесь с новым паролем. Затем снова откройте **Command Prompt** и отмените временную замену, восстановив обычную работу специальных возможностей.

* Нажмите **Start** или клавишу **Windows**.
* Найдите `cmd` или Command Prompt.
* Нажмите правой кнопкой на **Command Prompt** и выберите **Run as administrator**.
* Запустите от администратора.
* Выполните `copy c:\windows\system32\utilman.exe.bak c:\windows\system32\utilman.exe /y`.

  ![Восстановление исходного Utilman.exe](/assets/y9B0AGVAxYeSyeZVyaDis-AaZMHRJ5B0KXoxSBSrc0C-20241101-094710.png)

Пароль администратора Windows Server изменён.
