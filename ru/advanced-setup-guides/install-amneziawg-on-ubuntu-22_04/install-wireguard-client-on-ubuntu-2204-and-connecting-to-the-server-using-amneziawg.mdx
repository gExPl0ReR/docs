---

Чтобы подключить локальный компьютер к удалённому WireGuard VPN с ранее полученной серверной конфигурацией AmneziaWG, выполните следующие шаги. Руководство рассчитано на Ubuntu 22.04: установим ПО, настроим его и запустим VPN-соединение.

### 1. Измените sources.list клиентской ОС {#1-change-sources-list-on-the-client’s-operating-system}

Откройте терминал и сохраните копию sources.list:

```shell
sudo cp /etc/apt/sources.list /etc/apt/sources.list.backup
```

Откройте файл:

```shell
nano /etc/apt/sources.list
```

**Раскомментируйте строки deb-src:** удалите `#` в начале тех строк `deb-src`, которые нужно включить.

```shell
#Example sources.list file for Ubuntu 22.04

# newer versions of the distribution.
deb http://archive.ubuntu.com/ubuntu jammy main restricted
```

**Сохраните и выйдите.**

### 2. Обновите систему {#2-upgrade-the-system}

```bash
apt update && apt upgrade && apt-get full-upgrade && apt install resolvconf
```

### 3. Установите AmneziaWG на Ubuntu 22.04 {#3-install-amneziawg-on-ubuntu-22-04}

```bash
apt install -y software-properties-common python3-launchpadlib gnupg2 linux-headers-$(uname -r)

add-apt-repository ppa:amnezia/ppa

apt-get install -y amneziawg
```

Проверьте наличие всех необходимых драйверов:

```bash
lsmod | grep amnezia
```

Если вывода нет, выполните:

```bash
modprobe amneziawg && lsmod | grep amnezia
```

### 4. Скопируйте клиентскую конфигурацию AmneziaWG в Linux Ubuntu {#4-copy-amneziawg-client-config-to-linux-ubuntu}

Выполните команду:

```shell
scp [username]@[server-ip-address]:/root/awg/wg-client1.conf /etc/amnezia/amneziawg/
```

Здесь:

* `username` — имя пользователя сервера.
* `server-ip-address` — IP сервера.
* `/root/awg/` — каталог клиентских конфигураций AmneziaWG.
* `wg-client1.conf` — файл конфигурации amneziawg.
* `/etc/amnezia/amneziawg/` — локальный каталог Linux-компьютера.

### 6. Переместите конфигурацию в каталог AmneziaWG {#6-move-configuration-to-amneziawg-directory}

Поместите конфигурацию в каталог AmneziaWG. Здесь wg-client1.conf — ранее скачанный с сервера клиентский файл:

```shell
sudo mv /etc/amnezia/amneziawg/wg-client1.conf /etc/amnezia/amneziawg/wg0.conf
```

Ограничьте права, чтобы предотвратить посторонний доступ:

```shell
sudo chmod 600 /etc/amnezia/amneziawg/wg0.conf
```

### 7. Запустите VPN-соединение WireGuard {#7-start-the-wireguard-vpn-connection}

Для запуска с этим файлом конфигурации выполните:

```shell
sudo awg-quick up wg0
```

При правильной настройке соединение WireGuard VPN будет установлено.

### 8. Проверьте соединение {#8-verify-the-connection}

Чтобы проверить активность:

```shell
awg show
ip 
```

Команда показывает имя интерфейса, сведения о пирах и статистику передачи данных активного соединения WireGuard.

### 9. Отключитесь от VPN {#9-disconnect-from-the-vpn}

Для остановки соединения:

```shell
sudo awg-quick down wg0
```

### 10. При необходимости включите автозапуск WireGuard {#10-optionally-enable-wireguard-on-boot}

Чтобы VPN запускался при загрузке:

```shell
sudo systemctl enable awg-quick@wg0
```

Чтобы отключить автозапуск:

```shell
sudo systemctl disable awg-quick@wg0
```

### Советы по диагностике {#troubleshooting-tips}

* Проверьте закрытый и публичный ключи и данные конечной точки в конфигурации.
* При проблемах соединения изучите подробные ошибки в системном журнале:

```shell
sudo journalctl -xe
```

После этих шагов вы сможете подключаться к AmneziaWG в Ubuntu.
