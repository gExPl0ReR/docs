## Установка OpenClaw на VPS EDIS Global {#install-openclaw-on-an-edis-global-vps}

OpenClaw — мощный инструмент автоматизации на основе ИИ, который может работать непосредственно на вашем VPS.\
В этом руководстве показано, как установить и безопасно запускать OpenClaw на **KVM VPS EDIS Global**.

---

## Рекомендуемые тарифы VPS {#recommended-vps-plans}

Для стабильной работы рекомендуем:

- **KVM Starter (2 ГБ RAM)** — для тестирования и небольшой нагрузки.
- **KVM Basic Plus (4 ГБ RAM, 2 vCPU)** — для стабильного длительного использования.

> Потребление памяти OpenClaw может быть значительным и зависит от нагрузки и интеграций.

---

## Требования {#requirements}

Перед началом вам понадобятся:

- Работающий **KVM VPS EDIS Global**.
- **Ubuntu 22.04 или новее**.
- Доступ root или sudo.
- Подключение к интернету.

---

## Шаг 1. Подключение к VPS {#step-1-connect-to-your-vps}

Подключитесь по SSH:

```bash
ssh root@YOUR_SERVER_IP
```

---

## Шаг 2. Установка OpenClaw {#step-2-install-openclaw}

Запустите официальный установщик:

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

Он автоматически:

- Установит необходимые зависимости (Node.js и другие).
- Установит OpenClaw.
- Подготовит систему к первоначальной настройке.

---

## Шаг 3. Первоначальная настройка {#step-3-run-onboarding}

Запустите мастер настройки:

```bash
openclaw onboard --install-daemon
```

Во время первоначальной настройки вы:

- Укажете ключи API, например OpenAI или Claude.
- Настроите интеграции (необязательно).
- Включите фоновую службу.

---

## Шаг 4. Доступ к веб-интерфейсу {#step-4-access-the-web-interface}

OpenClaw работает локально на порту **18789**.

Для безопасного доступа используйте SSH-туннель:

```bash
ssh -L 18789:localhost:18789 root@YOUR_SERVER_IP
```

Затем откройте в браузере:

[http://localhost:18789](http://localhost:18789)

---

## Рекомендации по безопасности {#security-recommendations}

OpenClaw имеет доступ к системе и может выполнять команды.

Для безопасной работы:

- **Не** открывайте публичный доступ к порту `18789`.
- Используйте SSH-туннель вместо открытия портов межсетевого экрана.
- Запускайте OpenClaw на **отдельном VPS**.
- Используйте ключи API с ограниченными правами.

---

## Дополнительно: добавление swap (рекомендуется для тарифов с 2 ГБ) {#optional-add-swap-recommended-for-2-gb-plans}

Если вы используете **KVM Starter (2 ГБ RAM)**, добавление swap повысит стабильность:

```bash
fallocate -l 4G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
```

---

## Управление службой {#managing-the-service}

Если OpenClaw установлен как фоновая служба, управлять им можно так:

```bash
systemctl status openclaw
systemctl restart openclaw
systemctl stop openclaw
```

---

## Устранение неполадок {#troubleshooting}

**Установка завершается ошибкой или аварийно прерывается**

- Убедитесь, что доступно не менее 2 ГБ RAM (рекомендуется 4 ГБ).
- При необходимости добавьте swap.

**Не удаётся открыть интерфейс**

- Проверьте, что SSH-туннель активен.
- Убедитесь, что OpenClaw запущен:

```bash
systemctl status openclaw
```

---

## Итоги {#summary}

- Используйте **KVM Starter (2 ГБ)** для тестирования.
- Используйте **KVM Basic (4 ГБ)** для рабочей эксплуатации.
- Установите приложение с помощью однострочного скрипта.
- Подключайтесь безопасно через SSH-туннель.
