<h2 id="locations-&amp;-availability">Локации и доступность</h2>

Инфраструктура VPS EDIS Global доступна в **50\+ локациях по всему миру**.

Для каждой локации доступен **машиночитаемый JSON-источник данных**, содержащий:

- Страну и город.
- Доступные тарифы.
- Цены.
- Тип CPU.
- Технологию дисков.
- Сетевые подключения.
- Включённый трафик.
- URL на нашем сайте.
- Категорию: entry-level, standard-vps, high-performance plans, high traffic plans.
- Адрес дата-центра.

### Источники данных локаций {#location-data-feeds}

Все источники используют одну схему:

```text
https://www.edisglobal.com/location-data/<location-slug>/data.json
```

<h2 id="network-&amp;-traffic-model">Сеть и модель учёта трафика</h2>

### Включённый трафик на VPS {#included-bandwidth-per-vps}

Каждый тариф VPS включает **определённый месячный объём трафика**, зависящий от:

- Локации.
- Уровня тарифа.

Вы можете **повысить тариф в любое время**.

В лимит входит **входящий плюс исходящий трафик**. Например, VPN, получивший и переславший 100 GB, использует примерно 200 GB лимита плюс служебные данные. См. [учёт трафика](/ru/faq/traffic-bandwidth/traffic-stats-refill-explained).

Сетевое подключение разделяется между VPS. Скорость внешнего канала хоста не является гарантированной выделенной скоростью отдельного VPS. Выделенный доступ в Интернет и индивидуальные договорённости о гарантированной полосе для VPS недоступны; заранее согласуйте количество и сроки крупных развёртываний.

---

### Traffic Pool: дополнительный трафик {#traffic-pool-model-additional-bandwidth}

Помимо трафика тарифа, EDIS Global предлагает **Traffic Pool**:

- Общий пул трафика для всех услуг аккаунта.
- Ручное или автоматическое назначение.
- Подходит для большого расхода и пиковых нагрузок.
- Единая цена во всех 50 локациях EDIS.
- Неназначенный Pool Traffic не сгорает; неиспользованный трафик, уже назначенный VPS, сгорает при следующем месячном пополнении этого VPS.

#### Режимы назначения трафика {#traffic-assignment-modes}

**Manual Hydration — ручное назначение**

- Кнопки портала: **+100 GB**, **+500 GB**, **+1 TB** и **+10 TB**.
- Выбранный объём списывается из общего пула и добавляется к текущему лимиту VPS.

**Auto-Hydration — автоматическое назначение**

- Выбираемый шаг для каждого VPS: **100 GB**, **200 GB**, **300 GB** или **500 GB**.
- Срабатывает при расходе **99%** текущего лимита VPS.
- Использует имеющийся остаток пула, не покупая трафик автоматически.
- Требует достаточного остатка для выбранного шага.

Документация: [https://docs.edisglobal.com/faq/traffic-bandwidth/traffic-pool](/ru/faq/traffic-bandwidth/traffic-pool)

## IP-адреса {#ip-addresses}

- Дополнительный IPv4: **5 € за IP**.
- Случайная смена IP: **5 € разово (NRC)**.
- Смена на выбранный IP: **10 € разово (NRC)**.

Каждому VPS выделяется собственный **диапазон IPv6, эквивалентный /64**. Это не отдельно маршрутизируемая сеть `/64`: для доступа к шлюзу локации адреса используют длину префикса `/48`. Одновременно можно настроить до 20 постоянных IPv6-адресов.

Смена IP: [https://docs.edisglobal.com/faq/ip-addresses/change-ip-address](/ru/faq/ip-addresses/change-ip-address)

## Оплата {#billing}

### Платёжные циклы {#billing-cycles}

- Ежемесячно.
- Ежеквартально.
- Раз в полгода.
- Ежегодно: один месяц бесплатно.

Почасовая оплата **недоступна**.

### Способы оплаты {#payment-methods}

- Банковская карта.
- PayPal.
- Криптовалюта.
- Apple Pay, Google Pay и Alipay.
- Прямое списание SEPA / ACH — только по приглашению.
- Банковский перевод SEPA / SWIFT — ручная обработка, пополнение баланса аккаунта от 250 EUR.

<Warning>
  Банковские переводы не подходят для регулярных ежемесячных платежей, срочных продлений или немедленной активации. Прямая оплата счёта переводом требует предварительного согласования и допускается в экстренных случаях, когда автоматические способы недоступны.

  Отправка перевода не делает счёт оплаченным. Пока бухгалтерия не получит, не идентифицирует и не назначит платёж вручную, действует обычная процедура неоплаты, которая может привести к приостановке, прекращению услуги и безвозвратному удалению данных.
</Warning>

Способы оплаты: [https://docs.edisglobal.com/faq/billing-lifecycle/accepted-payment-methods](/ru/faq/billing-lifecycle/accepted-payment-methods)

EDIS Global рассчитан на **интеграции с приоритетом автоматизации**.

### Order API {#order-api}

Программное создание, управление и получение списка услуг.

[https://docs.edisglobal.com/order-api-reference/order-api-welcome](https://docs.edisglobal.com/order-api-reference/order-api-welcome)

### Management API {#management-api}

Операции жизненного цикла VPS и управление сервером.

[https://docs.edisglobal.com/management-api-reference/authentication/create-auth-session](https://docs.edisglobal.com/management-api-reference/authentication/create-auth-session)

Order API доступен после регистрации с обычной проверкой аккаунта и использует email и пароль клиентского портала. Для Management API нужен один VPS; доступ осуществляется через сеанс, созданный с email и паролем. Включённая 2FA панели не требует дополнительного кода для API-запросов.

Собственные пользовательские данные Cloud-Init поддерживаются при переустановке, но не в первоначальном заказе. Предварительные условия, проверка наличия и готовности описаны в [Before you automate](/order-api-reference/order-api#before-you-automate). Для VPN-операторов доступно [развёртывание VPN-узла](/ru/commercial-vpn-hosting#deploying-a-vpn-endpoint).
