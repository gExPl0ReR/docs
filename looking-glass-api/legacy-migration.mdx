Use the versioned `/api/v1/` endpoints for new integrations. Existing `/API_ping.php` consumers need explicit changes to their input parameters and response parsing; the new ping route is not a drop-in response replacement.

## Choose the measurement you need

| Existing use | New request |
| --- | --- |
| Basic ICMP reachability | `GET /api/v1/ping?target=1.1.1.1` |
| TCP reachability on SSH port 22 | `GET /api/v1/port?target=1.1.1.1&port=22` |
| TCP reachability on RDP port 3389 | `GET /api/v1/port?target=1.1.1.1&port=3389` |
| Four-packet ping or route diagnosis | `POST /api/v1/probes` |
| Measurement from a selected region through one hostname | [Hub API](/looking-glass-api/global-hub) |

The exact legacy URL includes its suffix and capitalization: `/API_ping.php?ip=...`. `/API_ping` is not a documented extensionless route.

## Response changes

The legacy shape uses `status: "UP"` or `"no"` and fixed TCP flags for ports 22 and 3389. The new ping response uses `status: "complete"` or `"no_reply"`, packet counts in `summary`, and measurement metadata. It does not include TCP checks.

For new integrations:

1. Rename the target parameter from `ip` to `target`.
2. Parse the new [ping response](/looking-glass-api/ping), particularly `summary.received` and `status`.
3. Request [TCP checks](/looking-glass-api/port) separately only when needed; read `open`, `closed`, `timeout` and other statuses.
4. Handle non-200 HTTP responses, absent optional timing fields and [rate limits](/looking-glass-api/rate-limits).

The Austria Go legacy handler performs one ICMP observation plus independent one-second TCP checks for ports 22 and 3389. The new TCP endpoint allows a three-second connection timeout, so its timing and outcomes are not identical. Malformed or missing legacy IP input can produce an empty HTTP 200 body; the new API returns structured errors for invalid input.

## Availability and limits

All 50 regional nodes provide the six versioned API endpoints. The Austria legacy URL is served by the Go compatibility handler; do not assume that other nodes' legacy PHP URLs have identical behavior or limits merely because their versioned APIs are available.

On the Go compatibility route, legacy requests and `/api/v1/ping` share the **600-per-minute, 16-concurrent** quick-ping allowance. New TCP checks share the **120-per-minute, 8-concurrent** detailed-probe allowance. Both regional budgets also share node capacity.

No legacy retirement date has been announced. Migrate and validate consumers before removing their compatibility handling.
